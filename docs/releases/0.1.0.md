# PaperRoute Tracker v0.1.0

**Released:** August 20, 2026  
**Release type:** Stable — Reliable Core

PaperRoute v0.1.0 is the first stable release of the local-first academic manuscript tracker.

This release focuses on a reliable foundation: manuscript lifecycle tracking, journal submission history, editorial decisions, correspondence and files, spreadsheet import/export, portable backup/restore, installer-based updates, recovery safeguards, and a polished Windows interface.

## Highlights

- Track manuscripts across **Pipeline**, **Published**, and **File Drawer** shelves.
- Record journal submissions, manuscript numbers, dates, portal links, decisions, revision deadlines, correspondence, and related files.
- Surface overdue revisions, upcoming revision deadlines, long reviews, missing target journals, and recent rejections in **Needs Attention**.
- Import from the PaperRoute workbook format, the legacy tracker format, or arbitrary spreadsheets through the column-mapping wizard.
- Export the library to Excel.
- Create portable ZIP backups and perform validated restores with an emergency pre-restore backup.
- Use Light, Dark, or Follow Windows appearance modes.
- Install with Velopack and receive future Stable updates through PaperRoute.

## Stable-release hardening

The route from alpha to v0.1.0 concentrated heavily on data safety and release reliability:

- Automatic recovery from a valid manuscript backup when the primary local database is missing, blank, or corrupt.
- Preservation of damaged primary data for troubleshooting rather than silently overwriting it.
- Fail-closed startup when manuscript storage or schema metadata cannot be validated safely.
- Strict storage-schema validation with compatibility protections.
- Managed-file import/copy rollback safeguards.
- Deterministic, independently tested Needs Attention business rules.
- Fresh installations default to the **Stable** update channel while existing Preview users keep their saved preference.
- GitHub Actions are pinned to immutable commit SHAs.
- Release artifacts receive published SHA-256 checksums.

## UI and accessibility

The stable candidate received a dedicated accessibility and scaling pass:

- Keyboard-only navigation and focus behavior reviewed.
- Dark-mode contrast improved for inactive Needs Attention indicators.
- Manuscript Details spacing and action controls hardened for DPI scaling.
- File Drawer date and reason can be revisited and edited from Manuscript Details.
- File Drawer reason edits are recorded in manuscript history.
- Dashboard layout validated at **100%, 125%, 150%, 175%, and 200%** Windows display scaling.
- Single-item Published and File Drawer shelves avoid unnecessary internal scrolling when space is available.

## Compatibility

- Storage schema remains **1**.
- Existing schema-1 PaperRoute libraries remain compatible.
- Compatible legacy ManuscriptPipeline storage can still be migrated conservatively.
- Existing RC users keep their persisted update-channel preference.
- Fresh installations use **Stable** by default.

## Security and trust

PaperRoute is local-first: its core manuscript database does not require a PaperRoute account or cloud service.

The v0.1.0 release publishes SHA-256 checksums for packaged artifacts. Code-signing availability and Windows reputation behavior are tracked separately from checksums; checksums do not replace a signed executable.

## Updating from v0.1.0-rc.1

If your installed RC.1 build is still on the **Preview** channel, open **Settings → Updates** and switch to **Stable**, then check for updates after v0.1.0 is published.

As always, upgrades are designed to preserve the manuscript database, backup, settings, schema metadata, managed library, and externally linked files.
