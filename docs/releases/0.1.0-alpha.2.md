# PaperRoute Tracker v0.1.0-alpha.2

This alpha introduces PaperRoute's installed-app update foundation.

## New

- Windows installer powered by Velopack.
- In-app update checks from GitHub Releases.
- Preview and Stable update channels.
- Optional automatic update checks at startup.
- Manual **Check for Updates** command from the Data menu and Settings.
- Release notes shown before an update is downloaded.
- Download progress with automatic restart after installation.

## Testing focus

This release is specifically intended to establish the update path for later alpha and RC builds.

Please verify:

1. Install PaperRoute using the generated Setup executable.
2. Confirm your existing local manuscript library still loads.
3. Confirm Settings reports that automatic updates are available.
4. Leave the update channel set to **Preview** for alpha/RC testing.
5. Keep regular PaperRoute backups while testing prerelease builds.

The next prerelease will be used to prove that an installed alpha.2 can update itself successfully.
