# PaperRoute Tracker v0.1.0-alpha.3

This prerelease is the **automatic-update validation build** on the route to RC.

## New and improved

- Safe migration to PaperRoute's versioned local storage (`schema 1`) while retaining legacy data for rollback.
- Privacy-safe Diagnostics report with version, runtime, and storage information.
- Automated regression tests for persistence, migration, backup/restore, and spreadsheet import paths.
- More responsive Preferences and Diagnostics dialogs for varied window sizes and DPI scaling.
- **Copy Version Info** in About PaperRoute for quick troubleshooting.
- Cleaner GitHub Actions run names and cancellation of superseded CI runs.

## Update test

If you installed `v0.1.0-alpha.2` from the Preview Setup executable, do **not** install alpha.3 manually at first.

Instead:

1. Launch the installed alpha.2 build.
2. Open **Settings → Check for Updates...**.
3. Confirm PaperRoute offers `0.1.0-alpha.3`.
4. Download/apply the update and allow PaperRoute to restart.
5. Confirm **Diagnostics** reports `Version: 0.1.0-alpha.3` and `Installed build: Yes`.
6. Verify your manuscript library and settings remain intact.

A successful alpha.2 → alpha.3 update is the primary release criterion for this build.
