# PaperRoute Tracker v0.2.0

PaperRoute v0.2.0 expands the trusted local manuscript tracker into a richer research-workflow hub while preserving PaperRoute's local-first and preview-before-apply safety model.

## Highlights

- **Schema 2 metadata foundation** with validated migration from v0.1 schema-1 libraries.
- **Reusable authors and affiliations**, including manuscript-specific order, corresponding-author status, and ORCID-ready identities.
- **DOI + Crossref** lookup with selective preview-before-apply metadata enrichment.
- **ORCID** public-profile lookup and one-way import for identity, affiliations, and works.
- **BibTeX and RIS** import/export with duplicate protection and warnings for unsupported or ambiguous source fields.
- **Journal Library**, submission-portal shortcuts, preprint links, and OSF/project-style external links without storing publisher credentials.
- **Publication & CV Export** to plain text, Markdown, and HTML.
- **Reminders & Calendar** for revision deadlines, submission follow-ups, and custom manuscript reminders.
- **Portable `.ics` export** for Outlook, Google Calendar, Apple Calendar, and other compatible calendar applications.
- **Optional Windows startup reminder notifications**, disabled by default and designed to fail without blocking PaperRoute.
- **Canonical User Guide and searchable in-app Help**, including local/offline access where practical.
- Extensive responsive-layout polish discovered during the v0.2 smoke pass.

## Upgrade and data safety

PaperRoute v0.2.0 introduces **storage schema 2**. Existing schema-1 manuscript data is validated before migration. The prior schema metadata is preserved as `schema.v1.bak`, and PaperRoute fails closed rather than silently adopting invalid or future schema data.

Existing free-text co-author information remains preserved as legacy text. External integrations do not silently change manuscript lifecycle state, and imported publication/work placement remains an explicit user choice.

## Privacy

PaperRoute remains local-first. Manuscript workflow state, reminders, reusable metadata, and managed files remain usable without a cloud account. Crossref and ORCID lookups occur only when the user invokes those features. PaperRoute does not store publisher portal passwords.

Optional AI-assisted reviewer processing is **not part of v0.2.0**.

## Testing

The v0.2 release candidate is covered by **159 automated tests** plus focused Windows smoke testing for reminders, calendar export, revision deadlines, submission follow-ups, in-app Help, responsive layouts, and release-critical workflows.

The final release is published only after upgrade, backup/restore, clean-install, updater, UI, and packaging certification pass.
